## What changed

**The interface language now follows the address.** Mainland China gets Simplified Chinese, Hong Kong / Macao / Taiwan get Traditional Chinese, and everywhere else gets English. The switcher in the header still lets you choose: mainland visitors can pick Simplified Chinese or English, and every other region has all three.

**The site wears a Windows / Metro face**, and three leftovers were fixed with it: rounded corners that survived on the legal pages, a dark block that appeared behind a nav item on hover, and statistics labels that were too faint to read. The nav underline now follows the section you are actually looking at instead of staying on "Overview".

**Dark mode on the API reference page works.** Clicking the colour-scheme button used to switch to dark and straight back, which looked like nothing happened — the page loaded its script twice, so one click toggled twice.

**Announcements can be published per language.** Existing notices behave exactly as before; new ones may ship a Chinese version and an English version.

No API path, parameter or response format changed in this release.
